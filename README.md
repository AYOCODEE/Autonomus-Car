# Autonomous Car Project

## Overview
This project demonstrates the implementation of an autonomous car using deep learning techniques in the Webots simulation environment. The main objective is to explore how neural networks can be trained to control a robot’s movement within a simulated world, mimicking real-world navigation and perception tasks.

## Motivation
Autonomous vehicles have the potential to revolutionize transportation by improving safety and efficiency. Simulated environments like Webots allow researchers and hobbyists to experiment with algorithms and sensor integration before deploying solutions in real-world scenarios.

## Methodology
- **Simulation Environment:** Webots was used to create a realistic world where the car robot operates.
- **Deep Learning:** A neural network model was trained on sensor data to control the car's movement, including steering and speed.
- **Data Collection:** The robot’s sensors collected data as it navigated the environment, which was used to train and validate the model.
- **Implementation:** Jupyter Notebooks and Python scripts were used to develop, train, and test the neural network.

## Results
The car robot successfully learned to navigate the simulated environment, avoiding obstacles and following paths autonomously. The final model demonstrated robust performance in various scenarios within Webots.

## How to Run
1. Clone this repository.
2. Open the Jupyter Notebooks and follow the steps for data preprocessing, model training, and simulation.
3. Ensure you have Webots installed and configured for your operating system.
4. Run the simulation and observe the robot's behavior.
